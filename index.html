如何免費取得 Firebase 資料庫網址？（免信用卡、約 1 分鐘）

  1. 用 Google 帳號登入 Firebase Console → 點「建立專案」。
  2. 進入專案後，左側選單點 「Build（建構）→ Realtime Database」 → 點「建立資料庫」。
  3. 安全規則先選 「以測試模式啟動 (Test mode)」，按啟用。
  4. 複製資料庫上方顯示的 https://...firebasedatabase.app（或 .firebaseio.com）網址，貼到上方欄位即可！

手機開啟 & 傳給別人使用教學

1. 傳給同學 / 老師對帳核銷（最推薦）

  • 直接點上方 「匯出 Excel」（產生 .xlsx，含自動公式）或 「匯出 PDF」（產生正式 A4 報表）。
  • 將下載的檔案直接傳到 LINE 群組或寄 Email，對方手機點一下就能看，完全不會跑版。

2. 把「可互動網頁版」傳給別人或換手機打開

  1. 先點 「更多 ▾ → 另存含資料的新網頁 (.html)」，把您新增的商品都打包進檔案。
  2. 注意不要直接用 LINE 內建預覽打開 .html！（LINE 會擋掉編輯與存檔功能）
  3. iPhone 開法：在 LINE 收到檔案後點「分享 → 儲存到檔案」，打開「檔案 App」找到該檔，點右下/右上分享選「在 Safari 中打開」（或使用「HTML Viewer / Documents」App）。
  4. Android 開法：在 LINE 收到檔案後下載到手機，打開手機的「檔案管理 / Downloads」，點檔案選擇「Chrome 瀏覽器」開啟。

3. 想變成「網址」直接貼在 LINE 裡點開？

  • 到電腦開啟免費空間 Netlify Drop（app.netlify.com/drop）或 GitHub Pages，把 index.html 拖曳上傳。
  • 系統會產生一個網址（如 https://xxx.netlify.app），貼到群組大家點連結就能在手機上看！
